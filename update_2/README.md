# ONERA M6 Wing Aerodynamic Analysis and Optimization

## Overview

This project focuses on aerodynamic analysis of the ONERA M6 wing using
Computational Fluid Dynamics (CFD). The ONERA M6 wing is a standard
benchmark model widely used for validating CFD solvers in transonic flow
conditions.

The project studies pressure distribution, lift and drag coefficients,
and shock wave behavior over the wing surface. The analysis helps
understand how aerodynamic forces change under different flight
conditions and how wing performance can be improved.

## Problem Statement

Modern aircraft operate in transonic conditions where shock waves appear
on the wing surface. These shocks increase drag and reduce aerodynamic
efficiency.

The ONERA M6 wing is used as a benchmark model to study: - Shock wave
formation - Pressure distribution - Aerodynamic forces on the wing

Understanding these effects helps improve aircraft wing design.

------------------------------------------------------------------------

## Project Objectives

The objectives of this project are:

-   Perform CFD analysis on the ONERA M6 wing
-   Study aerodynamic characteristics under transonic flow
-   Analyze pressure distribution across the wing
-   Calculate lift and drag coefficients
-   Observe shock wave formation on the wing surface

------------------------------------------------------------------------

## Methodology

### 1 Geometry Preparation

The ONERA M6 wing geometry is prepared using its standard configuration.

Features: - Swept wing - No twist - Symmetric airfoil sections

------------------------------------------------------------------------

### 2 Mesh Generation

A computational mesh is generated around the wing to simulate airflow.

Mesh characteristics: - Hybrid mesh - Structured layers near wing
surface - Fine mesh near boundary layer

------------------------------------------------------------------------

### 3 CFD Simulation

The airflow around the wing is simulated using CFD solvers.

The simulation solves the **Navier--Stokes equations** to compute:

-   Velocity field
-   Pressure distribution
-   Shock waves
-   Aerodynamic forces

------------------------------------------------------------------------

### 4 Aerodynamic Analysis

The following parameters are evaluated:

**Lift Coefficient (CL)**\
Measures the lifting force generated by the wing.

**Drag Coefficient (CD)**\
Represents aerodynamic resistance.

**Pressure Coefficient (Cp)**\
Shows pressure distribution across the wing surface.

------------------------------------------------------------------------

## Simulation Conditions

  Parameter         Value
  ----------------- ------------
  Mach Number       0.84
  Angle of Attack   3.06°
  Reynolds Number   14.6 × 10⁶
  Temperature       300 K

These conditions simulate transonic flight where shock waves appear on
the wing.
